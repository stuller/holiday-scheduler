# Holiday On-Call Draw

A small static app for drawing holiday on-call assignments fairly. Add teammates to the roster, then draw one person at a time. A person cannot be selected again until everyone has had a turn. The roster and round progress are saved in the current browser.

## Run locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch to publish and the `/ (root)` folder, then save.

GitHub Pages will publish `index.html` from the repository root. No build step or server is required.
